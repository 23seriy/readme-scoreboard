# League Workflow Examples

Copy a step below into your workflow. Add a matching marker pair to your README first.

## NBA

```yaml
- uses: 23seriy/readme-scoreboard@v1
  with:
    gh_token: ${{ secrets.GH_TOKEN }}
    target_repo: ${{ github.repository }}
    sport: nba
    team: ATL
    marker: readme-scoreboard-nba
```
